# Simulador de Plazo Fijo

Aplicación desarrollada con React que permite simular inversiones de plazo fijo mediante consumo de APIs externas para cálculo de intereses e historial de simulaciones.

---

## Funcionalidades

- Simulación de plazo fijo mediante API (POST)
- Validaciones de formulario:
  - Monto mínimo: $1000
  - Plazo mínimo: 30 días
  - TNA máxima: 50%
- Visualización de resultados:
  - Capital invertido
  - Plazo
  - TNA aplicada
  - Intereses ganados
  - Monto total
- Historial de simulaciones mediante API (GET)
- Visualización de hasta 20 registros históricos
- Formato monetario en pesos argentinos
- Diseño responsive

---

## Tecnologías utilizadas

- React
- CSS3
- Fetch API
- JavaScript ES6
